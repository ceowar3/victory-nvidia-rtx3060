## Observed limitations

The Belobug Series S run on RTX 3060 still has user-reported 2 FPS and black cutscenes. A later instantaneous sample showed 6 FPS / 156.7 ms with 2141 draws in a different moment; this is not a matched-scene improvement. Compute PSO creation fails with E_INVALIDARG; three observed compute shaders refuse partial-lane mask exchange. Placed texture UAVs can become null views and lose writes. Two-plane composition is already enabled by default. The exact cause of black cutscenes is unresolved.

The maintained paired runtime also has unresolved rendering faults and an investigated title-side memcpy crash. Do not treat unit tests or a successful build as proof that gameplay is fixed.

Prior local validation of the paired changes: shader 264 passed / 2 ignored; GPU 213 passed / 5 ignored; HLE 101 passed; loader 26 passed. These precede this publication snapshot. No GPU suite is rerun while the game is active.

No game executable, extracted shaders, assets, saves, local caches or private AI conversations are included. Build with the pinned Rust toolchain and `cargo build --locked --release -p victory`. This update does not promise stable 30 FPS.
