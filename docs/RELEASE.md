# Experimental Windows release

The release contains the runtime executable, portable launcher, license and
documentation. It contains no title executable, game archives, extracted shaders,
saves, generated shader caches, personal logs or credentials.

Supply your own compatible title files. Read README.md and BUILD-NOTES.md before
running. This build is experimental; stable gameplay and 30 FPS are not verified.

Source corresponding to this binary is supplied alongside it and in this
repository, under the licensing and attribution described in BUILD-NOTES.md.

Do not replace graphics driver DLLs or copy DLLs out of a commercial game. Install
Microsoft's current x64 Visual C++ runtime and Windows graphics components through
their official installers when required. Shader translation may require the
official DXIL validation component available through the Windows SDK; it is not
included in this binary package.
